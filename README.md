# Welcome to PSA Systems

[PSA Systems](https://PSA.Systems) manages every aspect of your MSP with business-friendly licensing: no vendor lock-in,
no split licensing, no self-hosting restrictions. 100% free and open source under the MIT license. Membership adds
community access, compiled binaries, and Docker images.

## Applications

- [Mokosh](https://msp.psa.systems) - Professional Services Automation (PSA) for Managed Service Providers (MSPs)
- [Let's Chat](https://chat.psa.systems) - Chat platform similar to Discord

## Development

Development takes place on [dev.a8n.run](https://dev.a8n.run/psa-systems). The repos are mirrored
to [GitHub](https://github.com/psa-systems) and [Codeberg](https://codeberg.org/psa-systems)

## Licensing

All code is licensed under an MIT license. No dual/EE (Enterprise Edition)/core licensing.

## Membership

Membership includes community access and Docker images. Pricing never increases for active memberships, rewarding early
adopters. A lapse in membership starts at the current price.
